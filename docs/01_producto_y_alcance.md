# 01 - Producto y alcance

## Producto final

Web oficial de `Juanma & The Center People` con CMS/backoffice para mantener contenido sin depender de desarrollo para cada cambio menor.

## Enfoque

El sitio debe funcionar como:

1. Página oficial para fans.
2. EPK para prensa y medios.
3. Herramienta de booking/contacto para productores.
4. Repositorio ordenado de contenido multimedia.
5. Sistema editable por responsable designado por la banda.

## Públicos objetivo

### Fans

Buscan:

- Escuchar música.
- Ver fotos y videos.
- Revisar fechas/eventos.
- Seguir redes sociales.
- Conocer la historia de la banda.

### Prensa/medios

Buscan:

- Bio corta y larga.
- Fotos oficiales.
- Datos rápidos.
- Enlaces a música.
- Press quotes si existen.
- Contacto.
- EPK descargable.

### Bookers/productores

Buscan:

- Contacto directo.
- Rider técnico.
- Stage plot.
- Formatos de show.
- Fotos/flyers/material promocional.
- Enlaces de música/video.

### Administrador/editor

Busca:

- Cambiar textos.
- Subir fotos/videos/reels/flyers.
- Organizar contenido.
- Activar/desactivar secciones.
- Aprobar solicitudes de descarga.
- Editar datos de contacto/redes.

## Principio clave

Cada tipo de usuario debe llegar rápido a lo suyo. La web debe ser clara, no un laberinto con guitarras.

## Alcance MVP

Debe incluir:

- Home.
- Banda.
- Música.
- Fotos.
- Videos.
- Reels.
- Prensa/EPK.
- Fechas/Eventos.
- Contacto.
- CMS/backoffice.
- Gestión multimedia.
- Umami analytics.
- Mailgun para contacto.
- Downloads públicos y downloads bajo aprobación.

## Fuera del MVP

No implementar inicialmente:

- Tienda.
- Fan club.
- Comentarios públicos.
- Newsletter avanzada.
- Sistema de pagos.
- Dashboard complejo.
- Multiidioma completo en la primera fase.
- Editor visual tipo constructor de páginas.

## Preparar para futuro

La arquitectura debe dejar listo el crecimiento hacia:

- Multiidioma.
- Más roles.
- Nuevos tipos de multimedia.
- Dominio final.
- Storage externo tipo S3/Cloudflare R2.
- Newsletter.
- Integraciones con redes.
